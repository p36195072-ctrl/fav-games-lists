# fav-games-lists
Favorite Game List

A beginner-friendly Python project that demonstrates how to store and display items using lists and loops.

📌 Description

This program creates a list of favorite games and uses a for loop to print each game one by one.

🧠 Concepts Used

Python Lists
for loop
Iteration
print() function

💻 Code

games = ["minecraft", "gta5", "cs2"]

for game in games:
    print(game)

▶️ Example Output

minecraft
gta5
cs2
